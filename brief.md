# Designity — краткое описание проекта

## Идея

Designity — веб-сервис для анализа нескольких визуальных референсов с помощью ИИ. Он помогает пользователю выявить сходства и различия между изображениями, выбрать подходящие визуальные характеристики и объединить их в целостное направление дизайна.

**Слоган:** Analyze. Combine. Create.

## Проблема

При создании визуального проекта пользователю может быть трудно сопоставить несколько референсов, выделить нужные характеристики и сформулировать на их основе единый дизайн-бриф.

Проблема пока является гипотезой и требует проверки интервью с потенциальными пользователями.

## Целевая аудитория

- Начинающие дизайнеры.
- Студенты, создающие визуальные проекты и презентации.
- Авторы другого визуального контента.

## Основной сценарий

1. Пользователь загружает несколько изображений.
2. Сервис анализирует визуальные характеристики каждого изображения.
3. Пользователь изучает сходства и различия между референсами.
4. Пользователь выбирает характеристики, которые хочет использовать.
5. Сервис формирует редактируемый дизайн-бриф.

## Основные функции MVP

1. Загрузка и проверка нескольких изображений.
2. ИИ-анализ визуальных характеристик, сходств и различий.
3. Формирование и редактирование дизайн-брифа на основе выбора пользователя.

## Ограничения

- Не разрабатывать регистрацию и авторизацию.
- Не добавлять совместную работу пользователей.
- Не реализовывать генерацию готовых изображений.
- Не добавлять функции, не необходимые для основного сценария.
- Не считать проблему подтверждённой до проведения интервью.

## Критерий полезности

Пользователь должен суметь пройти основной сценарий, понять результаты анализа, выбрать характеристики и получить дизайн-бриф, пригодный для дальнейшей работы.
